1. What this app does

The Part No. Generator builds two identifiers for engineered valves and actuators:

  • Part No. — a compact code that identifies a specific component (e.g. a Body, Bonnet, or Seat) of a given valve type, material, pressure class, and size.
  • Drawing NO. — a project-scoped identifier that ties a part to a year, project type, project code, and item number.

All reference data lives in a SQLite database (data.sqlite) on the server. When an administrator edits it and clicks Save, the change is written to that database and is instantly visible to every user the next time they load the page.

2. Using the Generator

  1. Project NO. — pick a Year, a Project Type, and type a Project Code of 3–4 digits.
  2. Item NO. — type 1–4 digits.
  3. Valve Type — start typing to filter. Pick an entry from the list.
  4. Part Name — type to filter. The list contains only parts of the chosen valve.
  5. Material — type to filter (e.g. 182 shows all A182 specs). Pick an entry.
  6. Class and Size — type to filter, then pick.
  7. Option — dropdown for the special treatment suffix.
Mouse wheel. All seven filter fields — Year, Project Type, Valve Type, Part Name, Material, Class, Size — respond to the mouse wheel the same way. Hover over the field (dropdown closed) and roll the wheel. The selection cycles through the entries without opening the dropdown. The new entry is committed immediately — no click needed. When the dropdown is open (because you clicked into the field or started typing), the wheel scrolls the list instead.
Filtering fields. The five type-to-filter fields (Valve Type, Part Name, Material, Class, Size) plus Year and Project Type let you type to filter the list. What you type is only a filter — it never becomes the value. A value is only accepted if it was picked from the dropdown (clicked) or reached via the mouse wheel. Leaving a field with unrecognised text reverts it to the previous selection.
  • Click into a field → the current entry stays visible, so you can delete or edit it.
  • Delete everything and click away → the field stays empty.
  • Type something that doesn't match, click away → the field reverts to the previous entry (or stays empty if there was none).
  • Click the ✕ to clear a value instantly. The ✕ is present on all seven filter fields, including Year and Project Type.
Assembly parts. When the selected Part Name is exactly Assembly, four things are disabled and greyed out at once: the Material field, the Option dropdown, the NACE checkbox, and the Norm. checkbox. All four corresponding codes are omitted from the Part No. For example, instead of 31-00-021N-A2-N2-T an assembly produces 31-00-A2-N2. All four controls return to normal (with empty values) when you pick a different Part Name. The Drawing NO. is unaffected — it uses only Year, Project Type, Project Code, Item NO., and Part Code.
Copying the result. Each output box — Part No. and Drawing NO. — has a small copy icon at its right edge. Click anywhere in the box (or the icon itself) to copy the value to the clipboard. The icon briefly turns green to confirm. Both boxes are dimmed and unclickable while the output shows a dash (—) — they activate as soon as a full code has been assembled.

3. Reference Tables

Click the Reference Tables tab to see the data behind the drop-downs. Six tables: Part List, Valve Types, Material, Class, Size, Special Treatment. In User Mode (green badge) they are read-only. Unlock Admin Mode to edit them.

4. Admin Mode

  1. Open the Reference Tables tab.
  2. Click Edit. A password prompt appears.
  3. Enter the admin password. The default is admin123.
  4. The badge switches to Admin Mode, and two extra buttons appear: Change Password and Lock.

While unlocked you can edit cells directly, add or remove rows, reorder them with Move Up / Move Down, and click Save to write everything back to the SQLite database.

5. Changing the admin password

Unlock Admin Mode, then click Change Password. Enter the current password, the new password twice, and save. Requirements: current password must be correct, new password must be at least 4 characters, and the two new-password fields must match. The new password is stored in data.sqlite and applies immediately.

6. Installation & the setup menu

The app consists of these files, all in the same folder:

FilePurpose
setup.batRun once, as Administrator. Configure the app, repair the database, or capture the current DB as the new defaults.
start.batStart the server. Run this every time you want the app online.
server.pyThe Python backend.
seed_data.pyAll built-in reference data lives here. Nothing is hardcoded in the HTML.
seed_tools.pyHelper used by setup option 3 to export the DB back into seed_data.py.
part_no_generator_html_v1.htmlThe user interface (this page).
data.sqliteThe database. Auto-built from seed_data.py on first start if missing.
config.txtCreated by setup.bat. Holds hostname, port, and bind address.
Python is required

If Python isn't already installed, download Python 3 from https://www.python.org/downloads/ and tick "Add Python to PATH" during installation. No third-party packages are needed.

Running setup.bat

Right-click setup.bat and choose Run as administrator. It presents three options:

OptionWhat it does
1 — Initial setupAsks for the address, port style, and LAN access. Writes config.txt, builds data.sqlite if missing, adds the hosts entry, sets up port forwarding and firewall rules. Safe to re-run — never overwrites an existing data.sqlite.
2 — Repair / Reset databaseDeletes data.sqlite and rebuilds it fresh from seed_data.py. All current data is lost. Requires typing YES to confirm.
3 — Update seed_data.pyReads the current data.sqlite and overwrites seed_data.py with its contents. This captures whatever you have in the app as the new built-in defaults. Requires typing YES to confirm.
Recommended workflow. First deployment: option 1. Later, to freeze your current data as the fallback defaults: option 3. If the DB gets corrupted: option 2 and it rebuilds from the last captured seed_data.py.

7. Starting and stopping the server

  1. Double-click start.bat. If the DB is missing, it's built automatically from seed_data.py.
  2. A black console window opens. When it says "Part No. Generator starting..." and lists the URL, the server is up. Leave this window open while the app is in use.
  3. Open a browser to the URL shown.

To stop: close the console window, or press Ctrl+C inside it.

Daily use: pin a shortcut to start.bat on the taskbar. The console window must stay open.
Multiple users

Several people can use the app at the same time. Each browser gets its own session. Only the person who unlocks Admin Mode can modify tables. If two admins click Save at the same moment, the second save replaces the first — have a single designated admin at a time.

8. The address and the hosts file

The address you chose (default: part-generator.eng) works because setup.bat added a line to this computer's hosts file. Verify with ping part-generator.eng — you should see 127.0.0.1. If it fails, re-run setup.bat option 1 or add the line by hand in C:\Windows\System32\drivers\etc\hosts:

127.0.0.1    part-generator.eng

Then run ipconfig /flushdns. hosts is per-machine.

9. Security

MeasureWhat it protects against
Reads are public; writes require loginAnyone can view tables. Only an unlocked admin can change them.
Session tokenAfter unlocking, every write call carries a random 32-byte token. Stale tokens expire after 4 hours.
Constant-time password comparisonPrevents timing attacks.
Request size cap (2 MB)Prevents memory exhaustion.
Only one HTML file can be servedNo directory traversal, no exposure of data.sqlite or server.py.
CSP, X-Frame-Options, Referrer-PolicyPrevents clickjacking and script injection.
Atomic database writesA crash mid-save leaves data.sqlite in its previous good state.
LAN mode is meant for trusted internal networks only. Do not expose this server to the public internet.

10. Backup & restore

Entire state is in data.sqlite. To back up: stop the server, copy the file somewhere safe, restart. To restore: replace the file, restart.

Extra safety: use option 3 in setup.bat to also freeze the current database as the defaults in seed_data.py. Then even if data.sqlite is lost entirely, option 2 will restore your data.

11. Forgot the admin password?

  1. Stop the server.
  2. Open a Command Prompt in the folder.
  3. Type python to enter a Python shell.
  4. Run: 
    import sqlite3
c = sqlite3.connect("data.sqlite")
c.execute("UPDATE meta SET value=? WHERE key='password_b64'", ("YWRtaW4xMjM=",))
c.commit(); c.close()
  5. Type exit(), then start the server again. Password is back to admin123.
Why "YWRtaW4xMjM="? That's base64 of admin123. To encode a different password: import base64; base64.b64encode(b"YourNewPassword").decode().

12. Editing the database directly

You can open data.sqlite with any SQLite tool — DB Browser for SQLite is a good free one. Stop the server first, edit, save, then restart.

Tables: meta, valves, classes, sizes, treatments, materials, part_headers, part_rows, years, project_types. Each table with a sort_order column uses that column for display order.

13. Troubleshooting

Opening the HTML directly (no server) — dropdowns and tables are empty
  • Expected. The HTML contains no reference data of its own — everything comes from the SQLite database through the server. Without a running backend, the app shows the interface but nothing can be loaded.
  • You'll see a red banner at the top saying "Server not reachable" to make this clear.
  • To use the app, start start.bat on the server machine and open the URL (e.g. http://part-generator.eng) instead of double-clicking the HTML file.
I typed in a filter field and it snapped back
  • The filter fields only accept entries that you clicked in the dropdown list or scrolled to with the mouse wheel. What you type is just a filter — it does not become the value.
  • If you type something and leave the field without picking an entry, the field reverts to whatever was selected before (or stays empty if there was none).
  • If you want to empty the field, delete all text and click away, or press the ✕ button.
Material, Option, NACE and Norm. are greyed out
  • The selected Part Name is Assembly. Assembly parts have no material, no special treatment, and no NACE/Norm. designation — all four controls are disabled intentionally and their codes are omitted from the Part No.
  • Pick a different Part Name to re-enable all four. When they come back, their values are empty — you'll need to select a material and any options you want again.
The mouse wheel scrolls the page instead of cycling entries
  • The wheel cycles entries only when the dropdown is closed. If you've clicked into the field or started typing, the dropdown is open and the wheel scrolls the list instead — that's by design.
  • Year, Project Type, Valve Type, Part Name, Material, Class, and Size all support the wheel. Option and the Project Code / Item NO. text inputs do not.
The copy icon in one box reverts to a tick and gets stuck
  • This shouldn't happen in the current version — rapid repeated clicks are handled. If you ever see it, reload the page. The checkmark always reverts to the copy glyph after 1.2 seconds.
Year or Project Type dropdown is empty
  • The years or project_types table is empty. Run setup.bat → option 2 to rebuild with default values, or unlock Admin Mode and add rows manually.
setup.bat says "This setup must run as Administrator"
  • Right-click setup.bat and choose Run as administrator.
Database is corrupted or missing tables
  • Run setup.bat → option 2 (Repair / Reset database). This rebuilds data.sqlite from seed_data.py. Back up the existing file first if you want to attempt recovery.
"Cannot reach the server" in the app
  • The console window running the server has been closed. Reopen it with start.bat.
  • The computer went to sleep. Wake it and refresh.
Other computers can't connect (LAN mode)
  • Check the firewall rule: netsh advfirewall firewall show rule name="Part No. Generator". If missing, re-run setup.bat → option 1 and enable LAN mode.
start.bat says "Configuration file is missing"
  • config.txt hasn't been created yet. Run setup.bat → option 1 first.
"Python was not found on this computer"
  • Install Python 3 from https://www.python.org/downloads/ and tick Add Python to PATH.
Port 1030 is already in use
  • Another instance of the server is still running. Close all black console windows and try again.
  • Or edit config.txt and change PORT=1030, then re-run setup.bat option 1 to rebuild the port-forward rule.

14. Keyboard and mouse shortcuts

  • ↑ ↓ — move through the filter list when a filter field is open.
  • Enter — pick the highlighted entry, or confirm in password dialogs.
  • Esc — abandon typing in a filter field and restore the previous entry, or close any open dialog.
  • Mouse wheel — hover over a closed filter field and roll to cycle through entries. The selection commits immediately.
